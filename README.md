# Sistema-de-gestion-VTV

Sistema de gestión para usuarios de verificaciones

El objetivo del mismo es brindar una mejor
interacción entre el usuario y el proceso de verificación, permitiendo al usuario tener un
mejor servicio a través de la gestión de su trámite y a sí mismo brindando información a la
empresa para mejorar la calidad de estos procesos mediante la retroalimentación.
La aplicación permitiría al usuario gestionar sus turnos, consultar y cargar la documentación
necesaria, realizar los pagos correspondientes y conocer previamente las distintas etapas
que componen la inspección para agilizar la misma.
Una de las principales funciones del módulo sería permitir el acceso al informe final de la
inspección, incluyendo sus resultados, mediciones y demás datos correspondientes.
Asimismo, el sistema conservaría un historial de las inspecciones realizadas sobre el
vehículo, permitiendo al usuario consultar la información de inspecciones anteriores.
Además, la aplicación incorporará mecanismos de retroalimentación mediante encuestas
posteriores a la atención. El usuario podría evaluar diferentes etapas del proceso, como la
gestión del turno, la recepción, los tiempos de espera, la información recibida y la
experiencia durante la inspección.
